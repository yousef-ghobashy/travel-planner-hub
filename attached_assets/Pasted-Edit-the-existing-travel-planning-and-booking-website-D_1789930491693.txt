Edit the existing travel planning and booking website. Do not rebuild the project from scratch and do not remove existing features. Keep the current structure, pages, components, and functionality unless specifically changed below.

Apply the following updates:

## 1. Use Free APIs / Free Tiers

Replace any placeholder or unnecessary paid API dependency with **free APIs or APIs that provide a usable free/developer tier** wherever possible.

Use appropriate free sources for:

### Flights

Use a legitimate flight API with a free/developer tier, such as:

* Amadeus Self-Service APIs
* Another legitimate flight-search API with a free tier

The flight system must retrieve real search results when the API supports it.

Do not fabricate flight prices, availability, airlines, durations, or booking information.

### Cities and Countries

Use free/open APIs such as:

* REST Countries
* GeoDB Cities free tier
* OpenStreetMap / Nominatim
* Other legitimate free geographic APIs

Use them for:

* Countries
* Cities
* Airports
* City/airport relationships
* Geographic information

### Hotels / Motels

Use free/open or free-tier APIs where available.

Possible sources:

* OpenStreetMap
* Overpass API
* Geoapify free tier
* Other legitimate accommodation/location APIs with free access

Support:

* Hotels
* Motels
* Hostels
* Apartments
* Resorts

Do not invent hotel availability, ratings, reviews, or prices.

### Attractions

Use free/open sources such as:

* OpenStreetMap
* Overpass API
* Wikidata
* Other legitimate free tourism/places APIs

### Maps

Use:

* OpenStreetMap
* Leaflet
* Mapbox free tier where appropriate

### Weather

Use a free API such as Open-Meteo where appropriate.

### Currency

Use a free exchange-rate API.

Keep the API architecture modular so providers can be replaced later without changing the frontend.

Modify the airport/city search so the **city name is the primary visible result**, not the airport abbreviation.

Do NOT make results look like:

**CAI**

Instead display:

**Cairo, Egypt**

Then show the airport information underneath:

**Cairo International Airport · CAI**

Examples:

Instead of:

CAI

Display:

**Cairo, Egypt**
Cairo International Airport · CAI

Instead of:

CDG

Display:

**Paris, France**
Charles de Gaulle Airport · CDG

Instead of:

JFK

Display:

**New York, USA**
John F. Kennedy International Airport · JFK

### Search behavior

The search should still accept:

* City name
* Airport name
* Airport code
* Country

But the result card/autocomplete should prioritize:

**City, Country**

with the airport name and IATA code as secondary information.

The IATA code should never be the main large title in the search result.
